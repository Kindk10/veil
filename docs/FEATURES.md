# VEIL — фишки уровня Telegram с флагами анонимности

Обозначения: 🔒 совместимо без оговорок · ⚠️ возможно с ограничением (анонимный аналог) · ❌ запрещено (ломает анонимность)

| Фича | Флаг | Решение |
|---|---|---|
| Голосовые звонки | 🔒 | WebRTC + DTLS-SRTP, сигналинг внутри рatchet-конвертов, постоянный битрейт + cover traffic |
| Видеозвонки | 🔒 | то же, видео-поток SRTP |
| Кружки (видеосообщения) | 🔒 | короткое видео, шифруется как медиа сессии |
| Прикрепление файлов | 🔒 | чанки AES-256-GCM ключом сессии, сервер видит только размер в сетке паддинга |
| Стикеры | 🔒 | паки как зашифрованные медиа-конверты |
| Пересылка сообщений/статей | 🔒 | зашифрованный пересылаемый объект; источник обрезается по умолчанию (не выдаёт чат-источник) |
| Анимации, темы, фоны чатов | 🔒 | чисто локальный UI, сервер не видит настройки |
| Архив чатов | 🔒 | локально в SQLCipher, без метаданных на сервере |
| Уведомления per-чат (вкл/выкл) | 🔒 | локальная настройка |
| Избранное (заметки) | ⚠️ | только локально в зашифрованной БД + E2E-синхронизация между своими устройствами; облачного хранения нет |
| Встроенный переводчик | ⚠️ | только on-device модель (~50–150 МБ); внешние translate-API запрещены — каждая переписка была бы утечкой |
| Голосования | ⚠️ | только внутри групп (1:1-опросы и «публичные на тысячи» исключены — деанонимизация по голосам) |
| Статусы (истории) | ⚠️ | адресные: видны только тем, кому вы их отправили; автосгорание 24 ч; публичных сторис нет |
| Фото/видео профиля | ⚠️ | шифруется, отдаётся только участникам сессий; «публичный аватар по юзернейму» — opt-in с предупреждением |
| Прочитано/чек-марки | ⚠️ | внутри конвертов, только получатель знает |
| Облачное хранилище как в Telegram | ❌ | запрещено: сервер не хранит расшифровываемого; заменено локальной зашифрованной историей |
| Публичные каналы с подписчиками | ❌ | метаданные подписчиков на сервере — запрещено; аналог позже: анонс-боты через onion (этап 3) |
| Вход по телефону/email | ❌ | не существует в системе |
| «Был(а) недавно» | ❌ | не существует (§5.2) |

## Порядок внедрения
1. **MVP-чат** (текст, файлы, медиа, самоуничтожение) — основа уже есть.
2. **Звонки + видеозвонки** (SRTP, CallKit/Android Telecom).
3. **Медиа-фичи**: кружки, стикеры, пересылка, реакции.
4. **On-device переводчик**, голосования, статусы-аналоги, профили.
5. **Темы/фоны/анимации** — параллельно на всех этапах.

Каждая фича входит только после проверки: «что нового узнает сервер?» — если ответ не «ничего», фича не выпускается.
