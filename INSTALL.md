# VEIL — установка

## Android
1. Скопируйте `VEIL-0.1.0-release.apk` на телефон (USB, мессенджер, облако — как удобно).
2. Откройте файл на телефоне → разрешите «Установка из неизвестных источников» для того приложения, которым открываете.
3. Установите → откройте → «Создать аккаунт»: PIN (4 цифры) + юзернейм.
4. Иконка: зелёный щит VEIL. Тёмная тема включена по умолчанию.

Требования: Android 8.0+. Приложение не запрашивает телефон, контакты, камеру — только сеть.

## iPhone (IPA, sideload — без Apple Developer)
Собранный `VEIL-0.1.0-ios.ipa` — unsigned: Apple требует личную подписку. Два бесплатных пути:

### Путь A — Sideloadly (Windows/Mac, 15 минут)
1. Установите iTunes (с сайта Apple, не из Store) и Sideloadly: https://sideloadly.io
2. Подключите iPhone кабелем, в Sideloadly выберите `VEIL-0.1.0-ios.ipa`, введите Apple ID.
3. Sideloadly подпишет и установит (используется бесплатный 7-дневный сертификат).
4. На iPhone: Настройки → Основные → VPN и управление устройством → доверьте своему Apple ID.
5. Каждые 7 дней открывайте Sideloadly → Refresh (или включите «auto refresh», если ПК всегда подключён).

### Путь B — AltStore (удобнее, автообновление)
1. Установите AltServer на ПК (Windows/Mac): https://altstore.io
2. Установите AltStore на iPhone через AltServer.
3. Перетащите `VEIL-0.1.0-ios.ipa` в AltStore на телефоне — приложение подпишется и установится.
4. Обновление подписи — автоматически при PC и телефоне в одной Wi-Fi сети.

### Полноценная подписка (без 7-дневного лимита)
Apple Developer Program — $99/год: если купите, пришлите команду/сертификат, я соберу
подписанный IPA через CI, устанавливающийся напрямую.
