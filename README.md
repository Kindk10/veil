# VEIL — зашифрованный анонимный мессенджер

Монорепозиторий: сервер-ретранслятор (Go) + клиент Android (Kotlin).
Спецификация протокола: `docs/PROTOCOL.md` — читать первым.

## Структура

```
veil/
├── docs/PROTOCOL.md          — спецификация (модель угроз, протокол, этапы)
├── server/                   — реле на Go: очереди зашифрованных конвертов,
│   ├── main.go                 без логов IP, без БД, без истории после доставки
│   └── crypto.go               проверка Ed25519-подписей запросов
└── client-android/core/      — крипто-ядро клиента:
    ├── Identity.kt             ключи из случайности на устройстве, ID = хеш ключа
    └── Transport.kt            трафик через Orbot/Tor (SOCKS 127.0.0.1:9050)
```

## Ключевые свойства

- Аккаунт = ключевая пара, создаваемая локально; сервер хранит только хеш.
- Телефон/email/имя не собираются — полей в модели данных нет.
- Все сообщения — Double Ratchet (прямая секретность), сервер не расшифровывает.
- Паролей и токенов нет: каждый запрос подписывается Ed25519.
- Tor-only режим по умолчанию: без Orbot клиент не отправляет ничего.
- `POST /erase` — сертификат стирания: полное безвозвратное удаление аккаунта,
  очередь и ключей на сервере; восстановление невозможно для кого угодно.

## Сборка сервера

```bash
cd server && go build -o veil-relay .
# запуск за TLS-терминатором (Caddy/nginx, TLS 1.3) или как onion-сервис tor
```
